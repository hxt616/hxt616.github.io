nano-vLLM（Continuous Batching 推理优化）

  • 项目描述：原 nano-vLLM 调度器将 Prefill 和 Decode 分离执行，导致单节点中 Batch 填充率低、GPU 利用率不足。在原项目上修改，实现 Continuous Batching 调度。
  • 核心实现：重构 Scheduler，实现 Prefill 与 Decode 请求的动态混合调度；修改 Model Runner，将两类序列统一拼接为单个 Batch，通过 flash_attn_varlen_func 统一计算 Attention。
  • 性能：在 RTX 4060 Laptop GPU（Qwen3-0.6B，ShareGPT 数据集，500条）上完成性能验证，推理吞吐由 200.6 tokens/s 提升至 352.3 tokens/s，提升 75%，主要得益于 Batch 合并与 Kernel Launch 开销降低。

tiny-flash-attention

  • 项目描述：基于 CUTLASS 简单复现 Flash Attention v2，理解算子级优化。
  • 核心实现：Online Softmax + Tile 化计算减少全局内存访问；cp.async 隐藏访存延迟；Shared Memory 缓存中间结果。
  • 性能：在 RTX 4060 Laptop GPU 测试环境下达到 26.8 TFLOPS。
